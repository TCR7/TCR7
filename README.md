### 👨‍💻 About Me 
Hi! I'm an aspiring Android developer passionate about creating meaningful and user-friendly mobile experiences. I'm currently focused on learning **Java** and **Kotlin**, and I'm diving deep into the fundamentals of **Android development**, including UI design, logic building, and automated testing. My journey into coding started with curiosity and the desire to build real-world applications. I'm particularly interested in improving my problem-solving skills through logic challenges and hands-on projects. Every day, I aim to write better code and learn something new — whether it's a programming concept, a tool, or a development pattern. I enjoy experimenting with small apps to reinforce what I'm learning. My first app, a classic **Jokenpo (rock-paper-scissors)** game, helped me understand key concepts like activities, user interaction, and the Android lifecycle. I'm also exploring **automated testing with Kotlin**, especially using **BDD (Behavior-Driven Development)** to write clean, testable code. Another area I'm excited about is gathering **mobile data usage statistics** in Android — understanding how apps behave in the background, and how to track data consumption. This is just the beginning of my journey, and I'm excited about what's ahead. I'm always open to collaboration, feedback, and learning opportunities. Let's build, break, and learn together! 🚀
